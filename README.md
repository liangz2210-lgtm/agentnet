# agentnet

开源网络的 agent 间通讯层。**里程碑 1：身份 + 中继通讯。**

规格见 [`SPEC.md`](./SPEC.md)（唯一事实来源），技术决定与实测依据见 [`DECISIONS.md`](./DECISIONS.md)。

> 状态：**施工中**。目前仅完成第 1~2 步（脚手架 + 身份模块），尚无可用 CLI。
> 完整安装与收发流程将在第 7 步补齐。

## 里程碑 1 的目标

两个独立的 agent 身份，通过一个中继互发端到端加密的消息。明确不做的事见 `SPEC.md` 第 10 节
（目录与标签、能力令牌、收据与计量、代币与链、LLM 调用、图形界面等）。

## ⚠️ 安全须知

### 私钥一旦丢失，无法找回

`agentnet init` 在你的本地数据目录里生成一份 secp256k1 私钥（默认 `~/.agentnet/identity.key`）。

- **这份私钥没有任何恢复机制** —— 没有助记词、没有云端备份、没有找回邮箱。
  文件删了就是永久失去这个身份，**别人发给它的消息再也无法解密**。
- 请自行备份。备份时务必保留其保管方式的安全性：副本同样应当是仅你可读的。
- 私钥**不接受**通过环境变量或命令行参数传入 —— 那会让它泄漏进进程列表和子进程环境。

### 身份文件的准入要求

加载时若发现以下任一情况，**程序拒绝运行**：

| 条件 | 要求 |
|---|---|
| 文件类型 | 必须是普通文件，**不得是符号链接** |
| 所有者 | 必须是**你自己** |
| 权限位 | 组与其他用户**不得有任何权限**（即 `0600`） |

数据目录所在的**每一级祖先目录**同样受检（不得是符号链接、不得对组或其他用户可写、
不得直接位于 `/tmp` 这类带 sticky 位的共享可写目录下）。

`init` 遇到已存在的身份**不会覆盖**。若写入中途失败，程序会先截断再删除残留文件；
万一连删除都失败，它会**明确告诉你残留文件的路径和手动处置步骤**（先备份再移走），
而不会自作主张删掉任何东西。

### 开发用中继是内存中继

本机集成测试使用 [`nak`](https://github.com/fiatjaf/nak)（版本锁定 **0.21.0**）作为本地中继。

- **`nak serve` 会把事件全部保存在内存里，进程重启后立刻清空。**
- 它**仅供开发与测试**，不得用于任何真实通信场景。
- 它还有三处细节值得知道：**不持久化**（`--help` 自述是 in-memory relay）、
`since` 采用**排他**语义（`>`，与 NIP-01 的 `>=` 不同）、`#p` 标签过滤正常。
详见 `DECISIONS.md` 第一部分 B。

### 重启后可能重复看到消息

消息去重表目前是**纯内存**的。进程重启后，中继上**尚未过期**的消息会被再次投递、再次显示。

这是已知限制（详细清单见 `DECISIONS.md` 第 17 节）。在里程碑 3 引入收据与计量之前，它必须改为持久化存储。

### 威胁模型的边界

身份模块的防线针对的是**其他 uid 的本地进程/用户**。

- **不防**以你自己身份运行的恶意程序 —— 它能直接读你的私钥文件，文件权限的主语是 uid 而不是进程。
- **不防** root。
- macOS 的 ACL（`chmod +a`）也不在 `0600` 检查的覆盖范围内。

完整边界与每条防线对应的攻击形态见 `DECISIONS.md` 第 0 节与第 9 节。
